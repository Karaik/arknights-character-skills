# Repository scope

This repository contains modular Arturia/Virtuosa roleplay skills, provenance-backed research, reviewed sticker candidates, and Koishi/ChatLuna export adapters.

- Maintain character facts separately from behavioral interpretations and group-specific information.
- Record verifiable source URLs, retrieval dates, page revisions when available, and asset hashes.
- Every sticker requires emotion labels, source class, selection rationale, usage and exclusion contexts, and an explicit review state.
- Only stickers explicitly approved by the owner may enter runtime manifests. New assets default to pending review.
- Preserve the distinction between official publication and community popularity. Popularity requires evidence.
- Do not commit credentials, group identifiers, chat databases, private transcripts, downloaded model weights, or generated live connection settings.
- Repository development does not authorize installing plugins, changing server configuration, or sending QQ messages.
- Validate exports against the pinned ChatLuna package API, not only a hand-written schema. Record runtime limits honestly.
